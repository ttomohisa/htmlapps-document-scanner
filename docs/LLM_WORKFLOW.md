# LLM Workflow

1. Read `AGENTS.md`, then `APP_SPEC.md` and `docs/ARCHITECTURE.md`.
2. Edit `src/index.template.html`; do not hand-edit `dist/`.
3. Keep the camera/image/PDF privacy boundary and `connect-src 'none'`.
4. Preserve the smartphone-first capture and three-column page workflow.
5. Build with `build-standalone.ps1` and run `scripts/check-repository.ps1`.
6. When behavior changes, update help copy, README files, APP_SPEC, and CHANGELOG together.
